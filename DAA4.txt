def knapsack(profits, weights, capacity):
    n = len(profits)

    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(1, capacity + 1):
            if weights[i - 1] <= w:
                dp[i][w] = max(
                    dp[i - 1][w],
                    profits[i - 1] + dp[i - 1][w - weights[i - 1]]
                )
            else:
                dp[i][w] = dp[i - 1][w]

    selected = []
    w = capacity

    for i in range(n, 0, -1):
        if dp[i][w] != dp[i - 1][w]:
            selected.append(i)
            w -= weights[i - 1]

    selected.reverse()

    return dp[n][capacity], selected

##Technique: Dynamic Programming using tabulation.
DP table: dp[i][w] stores the maximum profit using the first i items and capacity w.
Main decision: Use max() to compare including and excluding the current item.
Traceback: Move backward through the table to identify the selected items.
Complexity: Time is \(O(nW)\), and space is \(O(nW)\).

Time and Space Complexity
Let:
- \(n\) = number of items.
- \(W\) = knapsack capacity.
Time Complexity
1. Filling the DP table:

The outer loop executes \(n\) times, and the inner loop executes \(W\) times.

Therefore, the time complexity is:
\[
O(nW)
\]
2. Finding the selected items:

The traceback loop executes at most \(n\) times.

Its time complexity is \(O(n)\).

3. Overall time complexity:
\[
O(nW)+O(n)=\boxed{O(nW)}
\]
The DP table construction dominates the total running time.
Space Complexity
The DP table contains \((n+1)(W+1)\) entries.

Therefore, its space complexity is:
\[
O(nW)
\]
The selected-items list requires at most \(O(n)\) additional space.

Thus, the overall auxiliary space complexity is:
\[
\boxed{O(nW)}
\]
Viva point: The time complexity is called pseudo-polynomial because it depends on the numerical value of the capacity \(W\), not just on the number of bits needed to represent \(W\).

def knapsack(profits, weights, capacity):
    n = len(profits)

    items = sorted(
        [(profits[i], weights[i], i + 1) for i in range(n)],
        key=lambda x: x[0] / x[1],
        reverse=True
    )

    max_profit = 0
    best_items = []

    def bound(level, profit, weight):
        if weight > capacity:
            return 0

        result = profit
        total_weight = weight
        i = level

        while i < n and total_weight + items[i][1] <= capacity:
            result += items[i][0]
            total_weight += items[i][1]
            i += 1

        if i < n:
            result += (capacity - total_weight) * (
                items[i][0] / items[i][1]
            )

        return result

    def branch(level, profit, weight, selected):
        nonlocal max_profit, best_items

        if weight <= capacity and profit > max_profit:
            max_profit = profit
            best_items = selected[:]

        if level == n:
            return

        if bound(level, profit, weight) <= max_profit:
            return

        p, w, item_no = items[level]

        # Include the current item
        if weight + w <= capacity:
            branch(
                level + 1,
                profit + p,
                weight + w,
                selected + [item_no]
            )

        # Exclude the current item
        branch(level + 1, profit, weight, selected)

    branch(0, 0, 0, [])

    best_items.sort()
    return max_profit, best_items

##Time and Space Complexity
- Worst-case time complexity: \(O(2^n)\) nodes may be explored, with additional work for calculating bounds.
- Auxiliary space complexity: \(O(n)\) for the recursion stack and selected-item lists at a time, excluding sorting and temporary list allocations.
How This Implements Branch and Bound
1. Branch: Recursively explores including or excluding each item.
2. Bound: Estimates the maximum achievable profit using fractional knapsack.
3. Prune: Stops exploring a branch when its upper bound cannot exceed the current maximum profit.
4. Result: Returns the maximum profit and the selected item numbers.
