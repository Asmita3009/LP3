# Gradient Descent Algorithm

# Function
def function(x):
    return (x + 3) ** 2

# Derivative of function
def derivative(x):
    return 2 * (x + 3)

# Initial value
x = 2

# Learning rate
learning_rate = 0.1

# Number of iterations
iterations = 50

print("Gradient Descent")
print("----------------------------")
x_history = [x]
y_history = [function(x)]

for i in range(iterations):

    gradient = derivative(x)

    # Update x
    x = x - learning_rate * gradient
    x_history.append(x)
    y_history.append(function(x))
    print("Iteration", i + 1,
          "x =", round(x, 6),
          "y =", round(function(x), 6))

print("\nLocal Minimum:")
print("x =", round(x, 6))
print("y =", round(function(x), 6))

import matplotlib.pyplot as plt
import numpy as np

x_values = np.linspace(-6, 4, 100)
y_values = (x_values + 3) ** 2

plt.plot(x_values, y_values, label="y = (x + 3)^2")

plt.scatter(x_history, y_history,
            color="red", label="Gradient Descent Steps")

plt.scatter(-3, 0, color="green",
            marker="*", s=150, label="Minimum Point")

plt.xlabel("x")
plt.ylabel("y")
plt.title("Gradient Descent - Function Graph")
plt.legend()
plt.grid()
plt.show()

##3. Gradient Descent Update Rule
\[
\boxed{x_{\text{new}}=x_{\text{old}}-\alpha f'(x)}
\]
Where \(\alpha\) = learning rate = 0.1.

4. Minimum Point
\[
f'(x)=0 \Rightarrow 2(x+3)=0
\]
\[
\boxed{x=-3,\quad f(x)=0}
\]
2. Important Concepts
Concept	Meaning
Gradient Descent	Optimization algorithm used to minimize a function.
Gradient	Derivative indicating the slope and direction of change.
Learning Rate (\(\alpha\))	Controls the step size of each update.
Iterations	Number of times the value of \(x\) is updated.
Convergence	When successive updates approach the minimum.
Local Minimum	Lowest function value within a neighborhood.
Global Minimum	Lowest function value over the entire domain.
NumPy linspace()	Generates evenly spaced values for plotting.
Matplotlib plot()	Draws the function curve.
Matplotlib scatter()	Displays the optimization steps and minimum point.


3. Complexity
- Time Complexity: \(O(n)\), where \(n\) is the number of iterations.
- Space Complexity: \(O(n)\), because x_history and y_history store the iterations.
